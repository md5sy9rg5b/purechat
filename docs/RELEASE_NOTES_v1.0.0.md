## PureChat v1.0.0

不预置任何提示词的纯净版 Android 聊天客户端。

### 安装

下载下方 `PureChat.apk`，传输到手机后安装。首次安装需在系统设置里允许「安装未知来源应用」。

```bash
adb install -r PureChat.apk
```

### 首次使用

1. 启动后会弹出设置面板
2. 填入 API Key（可点「粘贴」按钮从剪贴板导入）
3. 点「校验连接」确认可用，再点「保存」

### 系统要求

- Android 8.0（API 26）及以上
- 需要联网；语音输入需麦克风权限

### 说明

- 对话与设置仅保存在本机，卸载即清除
- API Key 存储于应用私有目录
- 默认不开启联网搜索、文件解析等计费功能，需在设置里手动打开
